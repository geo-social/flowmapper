# Example notebooks

Notebooks that try the `flowmapper.org` package (`import flowmapper_org as fm`) on the example data
of the FlowMapper repository (<https://github.com/geo-social/flowmapper>, folder `Data`).

| Notebook | What it shows | Data |
|---|---|---|
| `00_parameters_guide` | **Start here.** Every setting of the Flows, Nodes and Regions tabs and the map, each shown with side-by-side maps; drawing options; a reference table of all keys and defaults | FamilyTree |
| `01_open_flowmapper_projects` | Load every `flowmapper_*.json` saved on FlowMapper.org, draw it next to the web site's picture, check the save/load round trip, restyle one | all project files |
| `02_build_maps_from_csv` | Build projects from node, flow and region files and style them step by step; small multiples over years; node measures; interactive widget and HTML map | Refugees/Ukraine, DisasterMigration/Katrina |
| `03_flow_styles_and_classification` | TAF, CHA, SHA flow styles, shape and bundling, classification, colour ramps that stand out, projections, dark mode | Bananas, FamilyTree |
| `04_migration_network_analysis` | Total-flow and net-flow node maps (diverging scheme with a white middle class), network measures, top flows, regionalization, flow matrix to flow list | Migration/Mexico, China, Rwanda |
| `05_recreate_flowmapper_org_maps` | The repository's FlowMapper.org maps rebuilt from CSV as setting *recipes*, each drawn as a zoomed high-contrast map | Ukraine, Katrina, Syria, Bananas, FamilyTree |

The bike-share data is not used: station-to-station trip flows need locational clustering (as in
flowmap.gl) to be readable; that is a TODO for FlowMapper.

**U.S. maps** are always zoomed to the lower 48 (`LOWER48`), never Alaska and Hawaii:
`map_image()` / `show()` apply it to any project whose nodes are mostly in the contiguous U.S.

## The look

The notebooks use figure-ground contrast: Tapered Fading Arc (TAF) flows in dark colours at full
opacity, pale regions (35 % opacity), and nodes sized by total flow and drawn on top of the flows.
`figure_ground()` in each notebook's setup cell sets these with ordinary FlowMapper settings, so the
projects still open on FlowMapper.org. `CONTRAST` adds two Python-only drawing options,
`flow_contrast` and `flow_halo`. Pass `contrast=False` to `show()` / `map_image()` to draw exactly
as FlowMapper.org does.

## Running

```powershell
cd D:\labgeosocial\python\flowmapper
.venv\Scripts\python.exe -m pip install -e ".[interactive]" jupyterlab
.venv\Scripts\python.exe -m jupyter lab notebooks
```

Choose the kernel **Python (flowmapper.org)**. The notebooks find the example data in the
repository they live in (`python/notebooks` → `Data`). Elsewhere, set `FLOWMAPPER_DATA` to the
`Data` folder of a clone of <https://github.com/geo-social/flowmapper> before starting Jupyter.

With the package installed from PyPI:

```powershell
git clone https://github.com/geo-social/flowmapper
cd flowmapper\python
python -m pip install "flowmapper.org[interactive]" jupyterlab
python -m jupyter lab notebooks
``` Maps, project files and HTML pages are written to
`notebooks/output/` (not tracked).

The notebooks are generated by `_build_notebooks.py`. Edit that script and run
`..\.venv\Scripts\python.exe _build_notebooks.py --run` to rebuild and execute them all
(`--run 00 06` for some).
